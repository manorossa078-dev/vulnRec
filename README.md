# vulnRec
Scanner for vulnerabilities in the networks or devices, as well as a simple password cracker for websites.

Cloning:
```bash
git clone https://github.com/manorossa078-dev/vulnRec.git
```
![](assets/cloning.png)

Setting it up:
```bash
cd vulnRec
chmod +x vulnRec bin/*
```
![](assets/setup.png)

Help:
```bash
./vulnRec -h
```
![](assets/help.png)

Usage:
```
./vulnRec -l
...
```
![](assets/usage.png)

Follow these steps and you'll install it completely.
